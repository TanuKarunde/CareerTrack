\# CareerTrack – AI-Powered Placement Preparation and Job Platform



CareerTrack is a full-stack web application designed to bridge the gap between students and employers. It helps students prepare for placements, improve their job readiness, analyze resumes, practice interviews, and apply for job opportunities. Employers can post jobs, manage applications, and find suitable candidates.



\## 🚀 Project Overview



The platform provides separate dashboards for Students, Employers, and Administrators, with role-based authentication and recruitment management.

\## ⚙️ Installation and Setup



\### 1. Clone the Repository



```bash

git clone https://github.com/TanuKarunde/CareerTrack.git

```



\### 2. Backend Setup



\- Open the `careertrack-backend` folder in Eclipse or your preferred Java IDE.

\- Configure your MySQL database connection.

\- Add the required API keys and application secrets to your local configuration.

\- Run the Spring Boot application.



Backend URL:



```text

http://localhost:8080

```



\### 3. Frontend Setup



Open a terminal and execute:



```bash

cd careertrack-frontend

npm install

npm run dev

```



Frontend URL:



```text

http://localhost:5173

```
